# License fallbacks / 许可补充

The npm archives for croact 1.0.4, croact-css-styled 1.1.9, css-styled 1.0.8 and keycon 1.4.0 declare MIT and carry Daybrush copyright banners in their ESM files, but omit a standalone license file. The adjacent text combines those banners with the MIT grant distributed by @daybrush/utils. The fallback is version-specific; review it when upgrading. isarray 1.0.0 includes its full license in README.md instead.

以上四个 npm 包声明 MIT，并在 ESM 文件头保留 Daybrush 版权声明，但未附独立许可文件。旁边的文本结合了这些版权声明与 @daybrush/utils 附带的 MIT 授权条款。构建按具体版本使用补充文本，升级时需重新核对。isarray 1.0.0 的完整许可位于 README.md。
